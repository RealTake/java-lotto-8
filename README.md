# 🎰 로또 (java-lotto-precourse)

## 📌 기능 요구사항

로또 발매기를 구현한다.

---

## 🧩 구현할 기능 목록

### 1. 입력 (InputView)

- [ ] 로또 구입 금액을 입력받는다.
    - [ ] 구입 금액은 1,000원 단위로만 입력 가능하다.
    - [ ] 숫자가 아닌 값 입력 시 예외를 발생시킨다.
    - [ ] 잘못된 입력 시 `[ERROR]` 메시지 출력 후 재입력받는다.
- [ ] 당첨 번호 6개를 입력받는다.
    - [ ] 쉼표(`,`)로 구분된 6개의 숫자를 입력받는다.
    - [ ] 중복 숫자 입력 시 예외를 발생시킨다.
- [ ] 보너스 번호 1개를 입력받는다.
    - [ ] 보너스 번호가 당첨 번호와 중복되면 예외를 발생시킨다.

---

### 2. 로또 발행 (LottoMachine)

- [ ] 구입 금액에 따라 로또를 발행한다.
- [ ] 1장의 가격은 1,000원이다.
- [ ] 1개의 로또는 1~45 사이의 중복되지 않은 6개의 번호로 구성된다.
- [ ] 로또 번호는 오름차순으로 정렬하여 저장한다.

---

### 3. 당첨 확인 (Result)

- [ ] 사용자가 구매한 로또 번호와 당첨 번호를 비교한다.
- [ ] 6개 일치 → 1등 (2,000,000,000원)
- [ ] 5개 + 보너스 번호 일치 → 2등 (30,000,000원)
- [ ] 5개 일치 → 3등 (1,500,000원)
- [ ] 4개 일치 → 4등 (50,000원)
- [ ] 3개 일치 → 5등 (5,000원)
- [ ] 2개 이하 일치 → 꽝
- [ ] 각 등수별 당첨 횟수를 계산한다.
- [ ] 총 수익률을 계산한다. (소수점 둘째 자리 반올림)

---

### 4. 출력 (OutputView)

- [ ] 구매한 로또 수량과 각 로또의 번호를 출력한다.
- [ ] 당첨 통계(각 등수별 일치 개수 및 상금)를 출력한다.
- [ ] 총 수익률을 출력한다.
- [ ] 출력 포맷은 요구사항의 예시와 동일하게 맞춘다.
